# Aurahealth – Health Assistant & BMI Calculator

A modular, interactive Python application that calculates Body Mass Index (BMI), ideal body weight, and personalized daily caloric recommendations based on individual health goals.

## Features
- **Dual Unit Support:** Accepts inputs in both Metric (kg/m) and Imperial (lbs/ft/in) units.
- **Health Categorization:** Classifies BMI scores into Underweight, Normal, Overweight, or Obese categories.
- **Calorie & Goal Planner:** Uses Mifflin-St Jeor formulas (BMR & TDEE) to calculate daily calorie targets based on specific goals (Weight Loss, Maintenance, or Weight Gain).
- **Interactive Terminal UI:** Features clean step-by-step guidance with execution loops allowing repeated runs.

## Tech Stack
- **Language:** Python 3.x
- **Concepts Used:** Modular Functions, Control Flow (While Loops), Conditional Logic, Unit Conversion Algorithms.
